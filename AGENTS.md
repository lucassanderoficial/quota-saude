# SaaS Development Operating Rules

Este projeto segue o padrão SaaS premium do Lucas.

## Skills obrigatórias
Antes de mudanças relevantes, usar:
- `domain-modeling` para entidades, papéis, permissões e vocabulário.
- `codebase-design` para arquitetura e separação de camadas.
- `vercel-react-best-practices` para React/Next/Vercel/performance.
- `frontend-design` e `ui-ux-pro-max` para UI/UX.
- `impeccable` para refinamento visual.
- `web-design-guidelines` para auditoria final.

## Regras permanentes
- Não criar interface genérica com aparência de IA.
- Desktop e mobile devem ser tratados individualmente.
- Componentes reutilizáveis e estados completos.
- Separar UI, regras de negócio, dados e integrações.
- Não alterar funcionalidades existentes apenas por estética.
- Validar responsividade, acessibilidade, build e superfície pública antes de concluir.
